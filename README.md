# Airport Rail Link Ticketing System

**Completed: June 5, 2025**

The **Airport Rail Link Ticketing System** is a Java-based application developed to simulate the ticket purchasing and travel card services of Bangkok's Airport Rail Link. The project applies fundamental programming and object-oriented programming concepts to create a functional system for managing passenger ticket purchases and related railway services.

The application allows users to select their starting and destination stations, calculate ticket fares based on their journey, and apply eligible discounts for specific passenger groups, such as students and senior citizens. It also includes payment processing functionality and support for travel card services, allowing users to create cards, top up their balances, and manage payments using stored value.

In addition to ticket purchasing, the system provides travel-related features such as estimating travel times between stations. The project was designed to demonstrate how Java and object-oriented programming principles can be applied to model a real-world transportation and ticketing system.

This project focuses on building practical experience with application logic, user interaction, fare calculation, conditional processing, data handling, and structuring a multi-feature Java application.

## Key Features

* Purchase railway tickets between Airport Rail Link stations
* Automatically calculate fares based on the selected journey
* Apply student and senior citizen discounts where applicable
* Process ticket payments
* Create and manage travel cards
* Top up travel card balances
* Estimate travel times between stations
* Provide an interactive user experience
